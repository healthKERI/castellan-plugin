Locksmith is a KERI identity and credential wallet application with plugin-enabled architecture. Whisper is a locksmith 
plugin for enterprise credential management; Weirwood is a standalone credential management server.

Whisper/weirwood is an enterprise credential management platform that supports issuing credentials with a single 
multisig identifier, per user, at a time. Only one weirwood will exist per company; multiple multisigs can exist per 
company. One non-multisig identifier will be uploaded to weirwood per user. Each user will manage their own instance of 
whisper, thereby one non-multisig identifier will exist per instance of whisper.
